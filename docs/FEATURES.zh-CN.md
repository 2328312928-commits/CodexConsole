# Codex 功能清单

[English](FEATURES.md)

Codex CLI 0.164.0 提供的功能（命令行、TUI 斜杠命令和 app-server 协议），以及它们在控制台中的位置。**控制台** = 网页界面（用 API 密钥登录），**API** = 使用密钥的公网 `/v1` API，**管理后台** = 管理区（需要所有者密码 + 验证器动态码）。密钥对沙箱、网络和审批的上限在控制台和 API 中同样生效；拥有完全访问和网络的密钥没有可再限制的内容。`npm run codex:check` 会对照已安装的 Codex 检查控制台用到的每个协议方法。

✅ 支持 · ⚠️ 支持但有限制（见说明） · — 不适用

## 不适用于网页控制台

| Codex 功能 | 原因 |
| --- | --- |
| 语音（`/voice`、实时对话） | 实验性的 WebRTC 音频接口；需要开通实时功能的账户才能测试，本次构建没有这样的账户 |
| Windows 沙箱设置（`/setup-elevated-sandbox`） | 主机是 Linux |
| Codex 云端任务、`codex apply`、远程控制、`exec-server`、共享守护进程（`codex agents`） | 云端和守护进程功能，没有本地 app-server 接口；控制台本身就是远程控制 |
| IDE 上下文（`/ide`）、转到桌面应用、工作树启动（`--worktree`） | 需要 IDE 或桌面应用；工作树可以先创建，再作为会话文件夹打开 |
| 仅终端的显示选项：主题、状态栏、标题、宠物、原始滚动、TUI 模式、快捷键重映射 | 网页界面有自己的主题切换（跟随系统 / 浅色 / 深色）和布局 |
| `codex update`、`completion`、`migrate-*`、`debug`、`sandbox` | 维护命令；Codex 版本固定在 `package.json` 中 |
| 其他提供商：API 密钥、OSS / 本地模型、Amazon Bedrock、网关 OAuth | 本控制台用于 ChatGPT 套餐；仍可在 `config.toml` 中设置提供商 |
| 个性（personality） | Codex 已弃用（不再改变风格） |
